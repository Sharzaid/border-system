# نظام التواصل في المنفذ
## الجوازات | الجمارك | سلاح الحدود

نظام ويب مستقل يعمل على الجوال والحاسوب، مع صلاحيات مستخدمين كاملة يتحكم فيها المدير فقط.

---

## المتطلبات
- Python 3.9 أو أحدث
- اتصال شبكة داخلي (أو استضافة)

---

## طريقة التشغيل (سريع)

### 1. تثبيت المتطلبات
```bash
cd border_system
pip install -r requirements.txt
```

### 2. تشغيل النظام
```bash
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000
```

### 3. الدخول
افتح من أي جهاز على الشبكة:
```
http://IP-الجهاز:8000
```

**حساب المدير الافتراضي:**
- اسم المستخدم: `admin`
- كلمة المرور: `Admin@123`

⚠️ **غيّر كلمة مرور المدير فوراً بعد أول دخول.**

---

## الصلاحيات

| الصلاحية | المعنى |
|---------|--------|
| **مدير النظام** | تحكم كامل + إدارة المستخدمين |
| **تسجيل حالات جديدة** | يستطيع إضافة حالات |
| **تعديل كل الحقول** | يستطيع تعديل كل بيانات الحالة |
| **تعديل الحالة فقط** | يستطيع تغيير الحالة وإضافة ملاحظات فقط |
| **بدون أي صلاحية** | اطلاع فقط (مثل سلاح الحدود) |

---

## كيف تضيف مستخدمين؟
1. ادخل بحساب المدير
2. اضغط «المستخدمون» من القائمة
3. اضغط «+ إضافة مستخدم»
4. حدد القسم والصلاحيات المناسبة
5. احفظ

---

## ملاحظات مهمة
- الجلسة تنتهي تلقائياً بعد **12 ساعة**
- قاعدة البيانات محفوظة في مجلد `data/border.db`
- النظام مصمم لعدد 15–50 مستخدم
- يعمل بشكل ممتاز على الجوال (تصميم متجاوب)

---

## تشغيل دائم (اختياري)
لجعل النظام يعمل باستمرار حتى بعد إغلاق الطرفية، استخدم مثلاً:
```bash
# Linux
nohup python -m uvicorn app.main:app --host 0.0.0.0 --port 8000 &
```

أو استخدم خدمة systemd / NSSM على ويندوز.
